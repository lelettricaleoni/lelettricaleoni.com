# SHA-256 per i file caricati — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ogni foto, video e GPX caricato (percorsi e modelli di bici) ottiene uno SHA-256
calcolato e salvato; un duplicato mostra un avviso bloccante con la possibilità esplicita
di procedere comunque; un GPX caricato con successo mostra subito un'anteprima del
tracciato.

**Architecture:** Due meccanismi, non uno: foto e GPX passano già dal nostro server
(`/api/upload`), che calcola lo SHA e blocca un duplicato *prima* di scrivere su R2. I
video vanno direttamente dal browser a R2 (upload presigned) e non toccano mai il nostro
server: il worker Python, che scarica già il sorgente per la transcodifica, calcola lo SHA
lì e lo consegna al sito estendendo il contratto di stato già esistente
(`videojob:v1:<key>` su Upstash) — il sito lo legge come dato non fidato, come fa già oggi.

**Tech Stack:** Next.js 16 (App Router, Server Actions), Drizzle ORM su Postgres/Supabase,
Cloudflare R2 (`@aws-sdk/client-s3`), worker Python separato
(`lelettricaleoni/videoStream-bucketWorker`, repo locale `C:\GitHub\videoStream-bucketWorker`).

**Spec:** `docs/superpowers/specs/2026-09-21-upload-sha256-design.md`

## Global Constraints

- Codice in inglese (identificatori, commenti); i testi rivolti all'admin nel pannello
  restano nella lingua già usata nei componenti che li ospitano (italiano nei toast/dialog
  esistenti di `media-upload.tsx`/`gpx-upload.tsx`)
- Nessun nuovo CDN esterno, nessuna nuova dipendenza npm — tutto qui si costruisce con
  `crypto` nativo di Node, `hashlib` nativo di Python, e componenti shadcn/ui già installati
  (`AlertDialog`)
- Migrazioni: generare con `drizzle-kit generate`, applicare con lo strumento MCP
  `apply_migration` su dev e produzione separatamente — mai `drizzle-kit migrate` (fallisce
  in silenzio da quando esiste una migrazione applicata via MCP, vedi `STATE.md`)
- Server Action per tutto ciò che parte dal nostro client; `/api/upload` resta una rotta
  perché la chiama anche codice non-nostro? No — resta una rotta perché deve accettare un
  body multipart/form-data grande via XHR con progress tracking, cosa che una Server Action
  non supporta altrettanto bene; è un'eccezione già esistente, non introdotta da questo piano
- Il worker vive in un repository separato con la propria pipeline: un merge sul suo `main`
  builda e **distribuisce automaticamente** l'immagine sulla VM di produzione, senza alcun
  controllo CI sul codice Python prima del merge (solo il workflow `Build & Push Docker
  image`, che builda ma non testa). Il Task 11 richiede quindi più cautela del solito e una
  verifica dal vivo dopo il deploy, non solo una revisione del diff

- [ ] **Step 1: Riscrivere la rotta**

Sostituisci l'intero contenuto di `app/api/upload/route.ts` con:

```ts
import { NextResponse } from 'next/server'
import { PutObjectCommand } from '@aws-sdk/client-s3'
import { eq } from 'drizzle-orm'
import { getAdminUser } from '@/lib/supabase/server'
import { s3, R2_BUCKET } from '@/lib/r2'
import { db, media, routes } from '@/lib/db'
import { sha256Hex } from '@/lib/hash'

async function findDuplicateOwner(kind: 'photo' | 'gpx', sha256: string) {
  if (kind === 'gpx') {
    const [match] = await db.select({ id: routes.id }).from(routes).where(eq(routes.gpxSha256, sha256)).limit(1)
    return match ? { routeId: match.id, bikeModelId: null as string | null } : null
  }
  const [match] = await db
    .select({ routeId: media.routeId, bikeModelId: media.bikeModelId })
    .from(media)
    .where(eq(media.sha256, sha256))
    .limit(1)
  return match ?? null
}

export async function POST(request: Request) {
  const user = await getAdminUser()
  if (!user) return new NextResponse('Unauthorized', { status: 401 })

  const formData = await request.formData()
  const file = formData.get('file') as File | null
  const key = formData.get('key') as string | null
  const kindRaw = formData.get('kind') as string | null
  const force = formData.get('force') === 'true'
  const kind = kindRaw === 'photo' || kindRaw === 'gpx' ? kindRaw : null

  if (!file || !key) return new NextResponse('Missing file or key', { status: 400 })

  const buffer = Buffer.from(await file.arrayBuffer())
  const sha256 = sha256Hex(buffer)

  if (kind && !force) {
    const owner = await findDuplicateOwner(kind, sha256)
    if (owner) {
      return NextResponse.json({ duplicate: true, sha256, owner }, { status: 409 })
    }
  }

  try {
    await s3.send(new PutObjectCommand({
      Bucket: R2_BUCKET,
      Key: key,
      Body: buffer,
      ContentType: file.type || 'application/octet-stream',
    }))
  } catch (err) {
    const msg = err instanceof Error ? err.message : String(err)
    console.error('R2 upload error:', msg)
    return new NextResponse(`R2 error: ${msg}`, { status: 500 })
  }

  return NextResponse.json({ key, sha256 })
}
```

Nota: `kind` è opzionale (`kindRaw` non riconosciuto → `null`) — un chiamante che non lo
manda salta semplicemente il controllo duplicati, comportamento identico a oggi.

```ts
'use server'
import { eq, ne, and } from 'drizzle-orm'
import { db, media } from '@/lib/db'
import { getAdminUser } from '@/lib/supabase/server'

/**
 * Called once a video's transcode job reports `done` with a sha256 — the
 * only moment the worker knows it, since the source file is gone right
 * after. Safe to call before the media row exists yet (a brand-new upload
 * not saved with the form): the UPDATE simply matches zero rows, and the
 * hash reaches the database anyway once the form is saved, carried through
 * mediaItems (see MediaUpload).
 */
export async function recordVideoHashAction(storageKey: string, sha256: string): Promise<{ duplicate: boolean }> {
  const user = await getAdminUser()
  if (!user) throw new Error('Unauthorized')

  const [existingMatch] = await db
    .select({ id: media.id })
    .from(media)
    .where(and(eq(media.sha256, sha256), ne(media.storageKey, storageKey)))
    .limit(1)

  await db.update(media).set({ sha256 }).where(eq(media.storageKey, storageKey))

  return { duplicate: Boolean(existingMatch) }
}
```

```ts
import { readFileSync } from 'fs'
import { join, dirname } from 'path'
import { fileURLToPath } from 'url'

// Eseguito fuori da `next`, che normalmente carica .env.local da solo — qui
// va fatto a mano, e prima di qualsiasi import da lib/db (che legge
// DATABASE_URL al momento in cui viene valutato il modulo).
const root = join(dirname(fileURLToPath(import.meta.url)), '..')
for (const line of readFileSync(join(root, '.env.local'), 'utf-8').split('\n')) {
  const eq = line.indexOf('=')
  if (eq === -1) continue
  const key = line.slice(0, eq).trim()
  const value = line.slice(eq + 1).trim()
  if (key && !(key in process.env)) process.env[key] = value
}

const { db, media, routes } = await import('../lib/db')
const { eq, isNull } = await import('drizzle-orm')
const { mediaPublicUrl } = await import('../lib/media-client')
const { sha256Hex } = await import('../lib/hash')

async function hashUrl(key: string): Promise<string> {
  const res = await fetch(mediaPublicUrl(key))
  if (!res.ok) throw new Error(`${res.status} fetching ${key}`)
  const buf = Buffer.from(await res.arrayBuffer())
  return sha256Hex(buf)
}

async function main() {
  const mediaRows = await db.select().from(media).where(isNull(media.sha256))
  const photoRows = mediaRows.filter((m) => m.mediaType === 'photo')
  console.log(`media senza sha256: ${mediaRows.length} (${photoRows.length} foto, resto video esclusi — vedi spec)`)
  for (const m of photoRows) {
    try {
      const hash = await hashUrl(m.storageKey)
      await db.update(media).set({ sha256: hash }).where(eq(media.id, m.id))
      console.log(`ok   ${m.storageKey}`)
    } catch (err) {
      console.error(`ERRORE ${m.storageKey}:`, err)
    }
  }

  const routeRows = (await db.select().from(routes).where(isNull(routes.gpxSha256))).filter((r) => r.gpxKey)
  console.log(`percorsi senza gpxSha256: ${routeRows.length}`)
  for (const r of routeRows) {
    try {
      const hash = await hashUrl(r.gpxKey!)
      await db.update(routes).set({ gpxSha256: hash }).where(eq(routes.id, r.id))
      console.log(`ok   ${r.gpxKey}`)
    } catch (err) {
      console.error(`ERRORE ${r.gpxKey}:`, err)
    }
  }

  process.exit(0)
}
```
